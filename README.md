# App Launcher

Небольшая программа для Windows: при входе в систему показывает сетку ваших приложений, вы отмечаете нужные — и одной кнопкой запускаете всё сразу. Запускать можно что угодно: программы, ярлыки, скрипты (`.bat`, `.cmd`, `.ps1`, `.py`…), документы, ссылки, папки.

## Возможности

- Сетка плиток со значками, перетаскивание для смены порядка, добавление файлов перетаскиванием в окно.
- Для каждой плитки (правый клик):
  - аргументы командной строки — включаются/выключаются щелчком по метке на плитке;
  - окно при запуске: обычное / свёрнутое / развёрнутое / скрытое;
  - приоритет процесса;
  - запуск от имени администратора;
  - задержка перед запуском;
  - автоматическое закрытие окна «крестиком» через N секунд после появления (процесс не убивается — приложение, например, уходит в трей).
- Автозапуск при входе в Windows.

## Сборка

Нужен только .NET Framework 4.x — он уже есть в Windows 10/11.

```
build.cmd
```

Результат — `bin\AppLauncher.exe`. Перед пересборкой закройте все окна лаунчера, иначе exe будет занят.

## Где хранятся данные

`%APPDATA%\AppLauncher\apps.ini` — обычный текстовый файл, его можно править вручную (кнопка ✎ в окне открывает его в блокноте, кнопка ⟳ / F5 перечитывает).

```ini
[settings]
close_after_launch = yes

[app]
name         = Telegram
path         = C:\Users\...\Telegram.exe
checked      = yes
args         = -startintray
args_enabled = yes
window       = normal
admin        = no
priority     = normal
start_delay  = 0
close_window =
```

- `window` — `normal` / `minimized` / `maximized` / `hidden`
- `priority` — `normal` / `low` / `below_normal` / `above_normal` / `high`
- `start_delay` — задержка перед запуском, секунд
- `close_window` — через сколько секунд после появления окна нажать «крестик»; пусто — не закрывать
- комментарии — отдельной строкой, начиная с `;`

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Enter | запустить отмеченные |
| Space | отметить / снять отметку |
| ← → ↑ ↓ | перемещение по плиткам |
| Alt+↑ / Alt+↓ | переместить плитку |
| F2 | переименовать |
| Del | удалить из списка |
| Ctrl+A | выделить все |
| F5 | перечитать список из файла |
| Esc | закрыть окно |

## Структура

```
src/
  Program.cs                 точка входа
  Model/LaunchItem.cs        плитка и её настройки
  Storage/AppConfig.cs       чтение/запись apps.ini
  Launching/Launcher.cs      запуск с учётом настроек
  Launching/LaunchWatcher.cs слежка за окнами/процессами после запуска
  Launching/Autostart.cs     автозапуск через реестр (HKCU\...\Run)
  Win32/Native.cs            WinAPI: процессы, окна
  Win32/ShellIcon.cs         значки файлов
  UI/Theme.cs                цвета, шрифты, DPI
  UI/MainForm.cs             главное окно
  UI/Prompt.cs               диалог ввода
  UI/Controls/               сетка плиток, кнопки, переключатель, тёмные меню
```

## Ограничения

- Свернуть/закрыть окно приложения, запущенного от администратора, нельзя — Windows не даёт обычной программе управлять такими окнами.
- Приложения из Microsoft Store и ссылки вида `steam://` запускаются, но слежка за их окнами и приоритет не работают.
